Dúvidas

É grátis mesmo?

Sim. O UltraChat é de código aberto e não tem plano pago.

O Windows disse “O Windows protegeu o computador”. E agora?

Isso aparece porque o instalador não tem assinatura digital paga. Clique em Mais informações → Executar assim mesmo. O código está todo no GitHub para quem quiser conferir.

Precisa colocar minha senha das plataformas?

Não. O UltraChat só lê o chat público da sua live, do mesmo jeito que um espectador.

Funciona junto com o StreamElements?

Sim. Os dois rodam lado a lado; o UltraChat só cuida do chat.

Como funcionam os pontos?

Cada pessoa ganha pontos por mensagem (com um intervalo para não valer spam), presentes, subs, bits, Super Chats e follows. Os valores e os ranks você define no painel. Por enquanto a mesma pessoa em plataformas diferentes tem pontuações separadas.

O bot responde no chat da plataforma?

Não. O UltraChat continua só lendo o chat, sem login. As respostas de !pontos, !rank e !top aparecem no overlay da live, para todo mundo ver.

O TikTok deu erro de “rate limit”.

A conexão com o TikTok usa um serviço gratuito com limite de uso. Crie uma chave grátis no eulerstream.com e cole em TikTok → Avançado no painel.

Como desinstalo?

Windows: Configurações → Aplicativos → UltraChat para OBS → Desinstalar.
macOS: sh ~/Library/Application\ Support/UltraChat/uninstall.sh
Linux: sh ~/.local/share/ultrachat/uninstall.sh
Em todos, a configuração do OBS é desfeita automaticamente.
